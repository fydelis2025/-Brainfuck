# 🧠 Brainfuck — Primeiros Passos & Projetos

> Descubra a essência da programação com apenas **8 comandos**

Repositório com códigos didáticos, interpretador próprio e exemplos funcionais da linguagem mais intrigante do mundo.

---

## 📂 Estrutura do Repositório

| Arquivo | Descrição | Conceito Principal |
|---|---|---|
| `app.py` | Interpretador de Brainfuck em Python (~50 linhas) | Execução e depuração |
| `01-ola-mundo.bf` | Mensagem "Alo Mundo!" | Básico: `+` e `.` |
| `02-imprimir-nome.bf` | Imprime `fydelistech` | Tabela ASCII |
| `03-somar-dois-numeros.bf` | 5 + 3 = 8 | Movimentação entre células |
| `04-contar-ate-10.bf` | Conta de 1 a 10 | Loops e conversão número→texto |
| `05-fatorial.bf` | 5! = 120 | Loops aninhados |

---

## 🚀 Como Executar

### Pré-requisitos
- Python 3 instalado → [python.org](https://www.python.org/)

### Passo a passo
```bash
# Clone ou baixe os arquivos
cd caminho/para/sua/pasta

# Execute qualquer exemplo
python app.py 01-ola-mundo.bf
python app.py 02-imprimir-nome.bf
python app.py 03-somar-dois-numeros.bf
